# 设计与验收清单

用于完整页面、改版和评审。审美默认值服从主 SKILL.md 优先级，不机械执行无关项。

## 设计判断

- 层级优先靠留白、字号与字重；容器和阴影需要有分组或层级作用。
- 强调色服务于重要动作，语义状态色按功能处理。
- 密度跟内容走，避免所有区块同样的间距、卡片与权重。
- 动效解释状态变化，高频操作尤其克制。
- 辅助文字保持可读，用字号和字重区分层级。
- 按钮、提示、空态、导航用词一致，文案真实具体。

以下是需要说明理由的常见模板套路，并非无条件禁用：

- 奶油/陶土/衬线、近黑/荧光、紫蓝渐变等顺手套用的组合。
- 永远居中大标题、说明、两个按钮的首屏，不分权重的三张等宽图标卡片。
- 过多大写标签、中点元信息、无意义编号与装饰性分隔线。
- 与内容无关的密集刊物排版，或全屏玻璃、网格、渐变边框。
- 每段滚动淡入上浮、每张卡片悬停位移，模板化占位文案和破折号语气。

用户指定这些风格时执行完整。记忆点来自内容和表达，不为反模板而强制所有页面采用另一套固定模板。

## 基线与真实验证

- 改前记录页面、视口、主题、状态、版本和测量口径，改后复用同一条件。
- 在 1440/768/375 等覆盖实际目标的视口检查溢出和遮挡，另检查缩放、长文案和不可断字符串。
- 普通文字至少 4.5:1，符合大字条件的文字至少 3:1；必要图形和状态指示按相邻背景检查 3:1。装饰和禁用项不机械套用正文阈值。判定用原值，展示才取小数。
- 检查真实颜色组合、主题和交互态。透明背景逐层合成；图片和渐变不能只取方便的一个颜色代表整块背景。
- 检查标题结构、地标、输入标签/错误信息关联、键盘顺序和焦点可见性，焦点不能被裁切或遮挡。
- 检查无动效选择和系统 prefers-reduced-motion，内容不能因关闭动画而不可见。
- 检查适用的正常、悬停、按下、焦点、禁用及业务状态，验证关键操作和实际数据流。
- 记录运行异常与控制台错误，区分业务错误、环境问题和探针误报。

圆角、阴影、动效种类计数可以发现不一致，但不是质量评分；只有项目约定上限才按上限验收。

## 容易漏的细节

- 中文标题在窄屏检查断词，必要时用有内容依据的断点，不以一次案例否定所有 text-wrap: balance。
- 长代码和 URL 允许换行或明确滚动，不对所有 code 使用 nowrap。
- 强调色区分文字、背景与装饰，每种用途都测实际组合。
- 切浅深底后重新检查次要文字、边界、图标、悬停和焦点。
- 离屏 iframe 不作为可靠截图证据；截图需要验证实际输出。
- 探针不能改写布局来修复结果；保留原始颜色、选择器、状态和异常值。
- 只清理本任务临时目录与进程，不按进程名关闭用户全部浏览器。

## 汇报

配置计算说明颜色组合范围；真实页面检查给出页面、视口、状态、读数和问题位置；视觉判断说明依据。未执行项写未验证。

示例：“普通文字 18 个组合中 17 个通过，最低失败值 3.8:1；375px 操作栏溢出 12px；键盘菜单未验证。”没有执行这些检查时不能复用示例数字。
